# TEMPLATE CATALOG - WHAT A REAL BUSINESS NEEDS

Templates are not a nice-to-have. They are the difference between a usable system and a blank editor that wastes time.

## Cross-Module Template Rules
- Every template must support variables, defaults, and validation.
- Templates need versioning and ownership.
- Users should be able to clone, lock, archive, and approve templates.
- Template usage should be visible in audit logs and analytics.
- Templates should be usable as defaults for new records, automations, and reports.

## What Is Missing Today
- Too many modules still assume the user will build everything manually.
- There is no template governance model.
- There is no shared variable system across modules.
- There is no business-grade template library with defaults by company type.
