# Security & Compliance Policies

- **Infosec Policy Pack**: Acceptable Use, Password, Access Control, Remote Access, Data Classification.
- **Vulnerability Management**: scheduled scanning, triage SLA, external pentest annually.
- **Patch Management**: timelines for OS and dependency patches; emergency patch procedures.
- **Secure SDLC**: threat modeling, SCA (software composition analysis), secret scanning in CI.
- **Encryption**: data-at-rest and in-transit requirements (TLS1.2+/AES-256), key lifecycle management.
- **Third-Party Risk**: vendor security questionnaire, SOC2 or equivalent evidence where applicable.
- **Audit Trail**: immutable logs for admin actions and critical operations; retention policy.
