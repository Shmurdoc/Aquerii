# DevOps & Infrastructure

- **Cloud Architecture**: network diagram, VPC/subnet segmentation, multi-AZ deployments.
- **Environments**: dev, staging, pre-prod, prod parity; automated promotion pipeline.
- **CI/CD**: pipelines include linting, unit tests, integration tests, security scanning, canary deploys.
- **Observability**: logs (structured), traces, metrics, dashboards, alerting policies.
- **Cost Controls**: budgets, alerts for billing anomalies, rightsizing audits.
- **Infrastructure Security**: hardened OS images, patch cadence, image signing.
- **DR & RTO/RPO**: documented recovery time objectives and tested disaster recovery runbooks.
