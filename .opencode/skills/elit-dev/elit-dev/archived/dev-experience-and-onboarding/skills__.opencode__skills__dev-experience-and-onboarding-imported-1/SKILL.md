# Developer Experience & Onboarding

## Purpose
Reduce time-to-productivity and friction for contributors by providing reproducible local environments, clear docs, and contributor flows.

## Activation Gate
Activate when new contributors join, or developer tooling is added/changed.

## Workflow Contract
1. Provide local dev scripts, containerized dev environments, and quickstart docs.
2. Maintain contributor guide, code of conduct, and PR templates.
3. Provide automated checks for style and linting in CI.

## Hard Rules
- Quickstart must get a new contributor to a running dev environment within 30 minutes.
- Documentation must include troubleshooting and common pitfalls.
