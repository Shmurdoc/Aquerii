# Developer Experience & Onboarding — Reference

Overview
- Quickstart, reproducible environments, contributor guides, PR templates, and local debug tooling.

Checklist
- Provide a `README.md` quickstart with steps to run locally and run tests.
- Offer a containerized dev environment (Docker/DevContainer) and scripts to seed test data.
- Include troubleshooting and common pitfalls section.

Automation
- `scripts/dev_up.sh` to start dependencies and the app locally.
- Tooling for format/lint/check pre-commit hooks and CI mirrors.

Onboarding Flow
- New contributor checklist: fork/clone, env setup, run tests, find a starter issue, open PR.
- Mentorship pairing suggestions and labels for good first issues.

Metrics
- Time to first PR merged, onboarding satisfaction, and build/test turnaround time.
